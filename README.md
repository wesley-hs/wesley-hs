## 👋 Sobre mim

Estou construindo minha carreira em **Qualidade de Software (QA)**.

Há mais de 6 anos trabalho com serviços técnicos (montagem de móveis e instalação de câmeras de segurança), onde nada é entregue ao cliente sem ser conferido e testado. Levo a mesma lógica para o software: entender como o sistema deveria funcionar, encontrar onde ele falha e documentar isso de forma clara para o time.

Estou no último período de **Análise e Desenvolvimento de Sistemas na PUC Minas** (conclusão em dez/2026), onde participei de projetos em equipe com Java, Spring Boot, C# / ASP.NET, React e bancos de dados. Essa base me ajuda a entender o que acontece por trás de cada bug.

## 📂 Projetos

### [Testes de API: ServeRest](https://github.com/wesley-hs/qa-api-serverest)
> Projeto de QA: do plano de teste ao bug report

Testes manuais e automatizados de uma API REST pública (usuários, login e autorização). Plano de teste, **30 casos de teste** com partição de equivalência e valor limite, automação em Postman rodando com Newman no GitHub Actions e **6 bugs reais reportados** como Issues, incluindo 3 de severidade alta (senha exposta, senha no token JWT e contas duplicadas por diferença de maiúsculas no e-mail).

`Postman` `Newman` `GitHub Actions` `GitHub Issues`

### [FitClub API](https://github.com/wesley-hs/fitclub-api)
> Projeto em equipe (PUC Minas): sistema de gestão para academias

Sistema para substituir o controle manual de alunos, pagamentos e treinos em pequenas academias. Atuei como **Scrum Master**, organizando sprints e acompanhando entregas, e trabalhei na integração entre back-end e app mobile, investigando e corrigindo falhas de comunicação (conflitos de versão, configuração de ambiente e formato de dados entre MongoDB e o app).

**Qualidade:** 18 testes automatizados com **JUnit 5 + Mockito** cobrindo as regras de negócio de treinos, planos e matrículas, e roteiro de testes manuais da API (cadastro → login → JWT → rotas protegidas) em arquivo `.http`.

`Java` `Spring Boot` `JWT` `MongoDB` `JUnit 5` `Mockito` `Docker`
